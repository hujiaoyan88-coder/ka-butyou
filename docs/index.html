復習の決まり

初回の学習日を入れると、復習が5回分出ます。日付はいつも「直前に実際にやった日」から数えます。予定どおりだと、学習日から次の並びです。

  1. 復習11日後前回から1日
  2. 復習23日後前回から2日
  3. 復習31週間後前回から4日
  4. 復習42週間後前回から7日
  5. 復習51か月後前回から16日

1か月は30日で計算しています。遅れて完了した日を入れると、その次からの予定が同じ日数だけ後ろへ動きます。早く終えたときも、その日から数え直します。

記録の控え

章を選ぶ

番号を押すと、その章の学習日と5回の復習日を編集できます。実施日を変えると、その次からの予定が動きます。
